# Arch Linux — your manual install guide

Generated by the [*nix Install Guides manual walkthrough](https://tilas01.github.io/Unix-SIT/manual.html).
Cross-check anything you are unsure about against the
[Arch Wiki installation guide](https://wiki.archlinux.org/title/Installation_guide) —
it is the authority, and where it and this disagree it is right.

> **Read this before running any of it.** The partitioning commands are
> aimed at `/dev/nvme0n1` and will destroy everything on it. They do not
> ask twice.

## 0. Before you boot the installer

1. **Verify the image.** Hash it, and get the checksum from a host other
   than the one that served the image — a server that lies about the
   image can hand you a checksum that matches the lie.
   [Verifier](https://tilas01.github.io/Unix-SIT/iso-verify.html).
2. **Lock the firmware down.** Update it, set a supervisor password,
   disable USB and network boot. Without a supervisor password every
   other setting is one unlocked menu away from being undone.
3. **Back up anything you cannot lose** — not to the disk below.

## 1. Boot the installer and get a network

```bash
ls /sys/firmware/efi && echo UEFI   # confirms firmware mode

# Wireless, if you need it:
iwctl station wlan0 connect YOUR_SSID

ping -c3 archlinux.org
timedatectl set-ntp true
```

## 2. Partition `/dev/nvme0n1`

```bash
lsblk                       # identify the disk by size and model. Twice.
```

```bash
gdisk /dev/nvme0n1
#   o → new GPT (destroys the existing table)
#   n → 1 → +512M → type ef00   (EFI system partition)
#   n → 2 → rest        → type 8300   (Linux filesystem)
#   w → write
```

### Format and mount

```bash
mkfs.fat -F32 /dev/nvme0n1p1
mkfs.ext4 /dev/nvme0n1p2
mount /dev/nvme0n1p2 /mnt
mkdir -p /mnt/boot
mount /dev/nvme0n1p1 /mnt/boot
```

## 3. Install the base system

```bash
pacstrap -K /mnt \
    base linux-firmware sudo vim man-db man-pages texinfo linux linux-headers linux-lts linux-lts-headers intel-ucode networkmanager efibootmgr zram-generator

genfstab -U /mnt >> /mnt/etc/fstab
cat /mnt/etc/fstab          # read it before you trust it
arch-chroot /mnt
```

## 4. Configure, inside the chroot

```bash
ln -sf /usr/share/zoneinfo/Europe/London /etc/localtime
hwclock --systohc

sed -i 's/^#en_US.UTF-8/en_US.UTF-8/' /etc/locale.gen
locale-gen
echo "LANG=en_US.UTF-8" > /etc/locale.conf
echo "KEYMAP=us" > /etc/vconsole.conf

echo "archbox" > /etc/hostname
cat >> /etc/hosts <<'EOF'
127.0.0.1   localhost
::1         localhost
127.0.1.1   archbox.localdomain archbox
EOF

passwd                                     # root password
useradd -m -G wheel -s /bin/bash you
passwd you
EDITOR=vim visudo                          # uncomment %wheel ALL=(ALL:ALL) ALL
```

## 5. Bootloader

```bash
bootctl install

cat > /boot/loader/loader.conf <<'EOF'
default arch.conf
timeout 3
console-mode max
editor no
EOF

UUID=$(blkid -s UUID -o value /dev/nvme0n1p2)
cat > /boot/loader/entries/arch.conf <<EOF
title   Arch Linux
linux   /vmlinuz-linux
initrd  /intel-ucode.img
initrd  /initramfs-linux.img
options root=UUID=$UUID rw
EOF
```

> `editor no` matters. Without it anyone standing at the boot menu can
> append `init=/bin/bash` and walk straight past your login — on an
> unencrypted system that is a full compromise in one keystroke.

## 6. Services

```bash
systemctl enable NetworkManager

cat > /etc/systemd/zram-generator.conf <<'EOF'
[zram0]
zram-size = min(ram / 2, 8192)
compression-algorithm = zstd
EOF
```

> zram compresses swap in RAM. Nothing from your memory is written to
> disk, which is one fewer place for a key to end up. It cannot
> hibernate — that needs real disk swap at least the size of RAM.

## 7. Reboot

```bash
exit
umount -R /mnt
reboot
```

> If it does not come up, boot the installer again, `cryptsetup open`,
> remount, `arch-chroot`, and you are exactly where you were. Almost
> nothing at this stage is unrecoverable.

## 8. After the first boot

Do this from the installed system, logged in as `you`.

```bash
sudo pacman -S --needed \
    hyprland waybar wofi xdg-desktop-portal-hyprland qt5-wayland qt6-wayland polkit-kde-agent pipewire pipewire-pulse pipewire-alsa wireplumber ttf-jetbrains-mono-nerd ufw git
```

### Firewall

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable
sudo systemctl enable ufw
```

> Default-deny inbound is the highest security-per-keystroke item in
> this whole guide. Everything you did not open is closed.

### Configure what you installed

These need a decision from you, so they are asked rather than guessed.

#### git

git refuses to commit without an identity, and it goes into every commit you ever make — including public ones.

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
```
