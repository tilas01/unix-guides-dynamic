What this project is

Four routes to the same install, so you can pick the one that suits how you think. Answer the questions and you get a script and a matching guide, with every command explained and nothing hidden — the script is the thing you read before you run it, not a black box.

The site is static and hosted on GitHub Pages. There is no account, no tracking and no server to send anything to; what persistence exists is your own browser's storage, and clearing it clears everything. Where this project and a system's official documentation disagree, the official documentation is right and this is a bug.

The security tools, briefly

Written in Rust, built and signed in CI, and each shipped with a section naming what it cannot do. They are optional. Several can lock you out of your own machine if misconfigured, which is why the tools page explains each one in full before you enable it.

libre-otpTwo-factor at boot, login and SSH, without a proprietary token.
anti-evil-maidBaselines the boot chain and tells you when it changes. Software hashing, not a hardware root of trust — and it says so.
anti-duckyBlocks BadUSB keystroke-injection devices pretending to be a keyboard.
kernel-watcherWatches the filesystem for infostealer and rootkit behaviour.
scarecrowCanary tokens, sandbox spoofing, and duress handling that never announces itself on screen.
pi-boot-guardRaspberry Pi boot integrity. Reports the EEPROM state and refuses to fuse OTP, which is irreversible.
aur-guardReads a PKGBUILD before you build it. Never needs root.
